# Creating & Loading External Checkpoints

This guide explains how to create a PhenoMe-compatible HDF5 checkpoint when you have embeddings or properties from an external source (e.g., a custom model or specialized image analysis tool).

---

## 1. The Core Requirement: Alignment

When you call `load_results()`, PhenoMe needs to match each row in your HDF5 file to the image files currently on your disk. You have two ways to do this:

### Option A: ID-based (Recommended)
**How it works:** You provide a unique identifier for each image.
- **In HDF5:** Include `/metadata/id` (one unique string per row).
- **In Code:** Call `pipeline.find_files(image_dir)` first.
- **Matching:** The pipeline matches your HDF5 IDs to the IDs generated by `find_files`.
- *Note: By default, `find_files` uses the filename stem (e.g., `cell_01` for `cell_01.png`) as the ID.*

### Option B: Path-based
**How it works:** You provide the literal file path.
- **In HDF5:** Store absolute paths in `/img_path` (or relative paths + `_storage_root` attribute).
- **In Code:** Call `pipeline.set_file_df(df)` with a DataFrame containing a `file_path` column.
- **Matching:** The pipeline matches rows where the path strings are identical.

> [!WARNING]
> If you use Option A (IDs) and your IDs do not match exactly, the alignment will fail silently, resulting in 0 images loaded.

---

## 2. HDF5 File Schema

Your `.h5` file should follow this structure. **Attributes** are metadata attached to the root `/` of the file.

### Root Attributes
| Attribute | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| `version` | `str` | **MANDATORY** | Must be `"2.0"` |
| `n_committed` | `int` | **MANDATORY** | Total number of images in the file |
| `embedding_dim` | `int` | **MANDATORY** | Dimension of vectors (set to `0` if none) |
| `n_committed_props` | `int` | **MANDATORY** | Number of rows with properties (set to `0` if none) |
| `_storage_root` | `str` | **OPTIONAL** | Base directory for resolving relative paths |
| `is_multichannel` | `bool` | **OPTIONAL** | Set to `True` if using `/img_path_channels` |

### Datasets & Groups
- **`/img_path`** (Dataset, $N$ strings): **[MANDATORY]** The primary image paths.
- **`/embeddings`** (Dataset, $N \times D$ float32): **[OPTIONAL]** The feature vectors.
- **`/metadata/`** (Group): **[OPTIONAL]**
    - `id`: (Strings) **Required for ID-based alignment.**
    - `[any]`: (Strings/Floats) Drug, Dose, Condition, etc.
- **`/properties/`** (Group): **[OPTIONAL]**
    - `[any]`: (Float32) Cell Area, Intensity, Texture, etc.

## 3. Implementation Example

This script creates a complete checkpoint and loads it into a pipeline.

```python
import h5py
import numpy as np
import os

# --- Configuration ---
DATA_DIR = "/path/to/images"  # Where your images live
N, D = 5, 128                 # 5 images, 128-dimensional embeddings

# --- 1. Prepare Data ---
# Image paths relative to DATA_DIR
img_paths = [f"image_{i}.png" for i in range(N)]

# Unique IDs for alignment (must match IDs from find_files)
img_ids = [f"image_{i}" for i in range(N)]

# Feature data
embeddings = np.random.randn(N, D).astype("float32")
drug_names = np.array(["DMSO", "DMSO", "DrugA", "DrugB", "Control"], dtype=object)

# Morphometric properties
cell_area = (np.random.rand(N) * 1000).astype("float32")

# --- 2. Write HDF5 ---
with h5py.File("external_results.h5", "w") as f:
    # Set MANDATORY root attributes
    f.attrs["version"] = "2.0"
    f.attrs["n_committed"] = N
    f.attrs["embedding_dim"] = D
    f.attrs["n_committed_props"] = N
    f.attrs["_storage_root"] = DATA_DIR  # Enables relative path resolution
    f.attrs["is_multichannel"] = False

    # Create datasets
    dt_str = h5py.special_dtype(vlen=str)
    f.create_dataset("img_path", data=np.array(img_paths, dtype=object), dtype=dt_str)

    if D > 0:
        f.create_dataset("embeddings", data=embeddings, compression="gzip", compression_opts=4)

    # Metadata Group (for alignment and labels)
    meta = f.create_group("metadata")
    meta.create_dataset("id", data=np.array(img_ids, dtype=object), dtype=dt_str)
    meta.create_dataset("drug", data=np.array(drug_names, dtype=object), dtype=dt_str)

    # Properties Group (for numerical analysis)
    props = f.create_group("properties")
    props.create_dataset("cell_area", data=cell_area)

# --- 3. Load in PhenoMe ---
from phenome.pipeline import PhenoMe

pipeline = PhenoMe()

# Discover images on disk (generates IDs like 'image_0', 'image_1'...)
pipeline.find_files(DATA_DIR)

# Load the checkpoint (matches /metadata/id in HDF5 to the discovered IDs)
pipeline.load_results("external_results.h5")

# verify
print(f"Loaded {pipeline.results.n_images} images.")
pipeline.plot_tsne(color_by="drug")
```

## 4. Common Variants

### A. Properties Only (No Embeddings)
Use this if you only want to use PhenoMe for property visualization (e.g., from CellProfiler).
```python
with h5py.File("props_only.h5", "w") as f:
    f.attrs["version"] = "2.0"
    f.attrs["n_committed"] = N
    f.attrs["embedding_dim"] = 0        # MANDATORY: set to 0
    f.attrs["n_committed_props"] = N    # MANDATORY: match row count
    # ... create img_path and /metadata/id ...
    # ... create /properties/ dataset ...
```

### B. Path-Only Alignment (No IDs)
Use this if you don't want to deal with IDs and have full absolute paths.
```python
# In HDF5: Store full absolute paths in /img_path
# In Python:
import pandas as pd
file_df = pd.DataFrame({"file_path": ["/abs/path/img1.png", "/abs/path/img2.png"]})
pipeline.set_file_df(file_df)
pipeline.load_results("abs_paths.h5")
```

## 5. Troubleshooting

| Symptom | Probable Cause | Solution |
| :--- | :--- | :--- |
| **0 images loaded** | IDs in HDF5 don't match `find_files` IDs. | Check `/metadata/id`. By default, it should be the filename without extension. |
| **Images not found** | `_storage_root` + relative paths are incorrect. | Print your absolute paths in Python and compare to the HDF5 `/img_path`. |
| **No PCA/UMAP plots** | `embedding_dim` is 0 or dataset missing. | Ensure `embedding_dim > 0` and the `/embeddings` dataset exists. |
| **Linter/Runtime Error** | Incorrect data types. | Paths/Metadata must be `vlen str`. Properties must be `float32`. |
