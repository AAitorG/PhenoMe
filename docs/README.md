# PhenoMe documentation site (Astro Starlight)

This directory builds the **public documentation** (search, sidebar, dark mode) with [Astro Starlight](https://starlight.astro.build/).

## Local preview

Requirements: **Node.js 20+**, **npm**, and **Python** matching the package (`requires-python` in the repo root `pyproject.toml`, currently **3.12+**).

API Markdown under `reference/api/` is produced by `scripts/generate_api_docs.py` (via `npm run prebuild` / `npm run dev`). That script **prepends the repository root to `sys.path`**, so `import phenome` works **without** `pip install -e .` as long as the same runtime dependencies are available in your environment.

**Recommended:** from the repo root, run `pip install -e .` so imports match CI and all dependencies are installed. If you skip the editable install, ensure your interpreter can still import `phenome` and its dependencies (otherwise the generator writes stub pages and prints the error).

```bash
cd docs
npm install
npm run dev
```

Open the URL printed in the terminal (usually `http://localhost:4321/PhenoMe/` because of the GitHub Pages `base` path). Keep the raster logo as **`src/assets/Logo.png`** (one file for both the Starlight header and the home splash hero). If you still have an old **`Logo.png`** next to `package.json`, move it once: `mv Logo.png src/assets/`.

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages (one-time setup)

1. Repository **Settings → Pages**
2. **Build and deployment**: Source = **GitHub Actions**
3. Merge to `main` / `master`: the **Documentation** workflow builds and deploys to `https://AAitorG.github.io/PhenoMe/`

If the site 404s, confirm **Actions** permissions allow **Read and write** for workflows and that the `github-pages` environment exists (created on first deploy).

## Content layout

| Path | Role |
|------|------|
| `src/content/docs/` | Markdown pages (guides, reference, home) |
| `src/content/docs/reference/api/` | Generated by `scripts/generate_api_docs.py` on each `npm run build` |
| `scripts/fix_markdown_links.py` | Normalizes Markdown links (removes `.md` extensions for Astro, fixes logo paths) on each build |
| `src/assets/Logo.png` | Canonical raster logo (Starlight nav + splash hero); commit this path in git |
| `public/` | Static assets served at site root (e.g. `favicon.png`) |
| `astro.config.mjs` | Starlight theme, sidebar, `site` + `base` (set to `/PhenoMe/` for GitHub Pages) |

## npm scripts cheat sheet

All commands below are run from the `docs/` directory.

| Script | What it runs | When to use |
|--------|--------------|-------------|
| `npm run sync-assets` | Ensures `src/assets/` and `public/` exist | Runs automatically before `dev` / `build` |
| `npm run fix-links` | `python3 scripts/fix_markdown_links.py` over `src/content/docs/` | Rarely, invoked automatically by `dev` / `build` |
| `npm run predev` | `sync-assets` + `generate_api_docs.py` + `fix-links` | Hook, runs automatically before `dev` |
| `npm run dev` | `astro dev` with hot reload | Daily authoring loop |
| `npm run prebuild` | Same three steps as `predev` | Hook, runs automatically before `build` |
| `npm run build` | `astro build` → writes `dist/` | Full production build (CI runs this) |
| `npm run preview` | `astro preview` on the `dist/` output | Verify the exact production bundle |

## Editing

- Narrative docs: edit Markdown under `src/content/docs/`.
- API synced with code: improve **docstrings** in `phenome/`; rebuild regenerates `reference/api/` (optional `@section` / `@order` lines at the start of a docstring control grouping on the site).
