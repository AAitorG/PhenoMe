# PhenoMe documentation site (Astro Starlight)

This directory builds the **public documentation** (search, sidebar, dark mode) with [Astro Starlight](https://starlight.astro.build/).

## Local preview

Requirements: **Node.js 22.12+**, **npm**, and **Python** matching the package (`requires-python` in the repo root `pyproject.toml`, currently **3.12+**).

API Markdown under `src/content/docs/advanced/api/` is produced by `scripts/generate_api_docs.py` (via `npm run build` / `npm run dev`). That script **prepends the repository root to `sys.path`**, so `import phenome` works **without** `pip install -e .` as long as the same runtime dependencies are available in your environment.

**Recommended:** from the repo root, run `pip install -e .` so imports match CI and all dependencies are installed. If you skip the editable install, ensure your interpreter can still import `phenome` and its dependencies (otherwise the generator writes stub pages and prints the error).

```bash
cd docs
npm install
npm run dev
```

Open the URL printed in the terminal (usually `http://localhost:4321/PhenoMe/` because of the GitHub Pages `base` path). Keep canonical static files under **`assets/`** (logo, favicons, figures, any new images). `npm run sync-assets` mirrors all of **`assets/`** into **`src/assets/`** before dev/build so Starlight and MDX can import them; edit and commit files only under **`assets/`**.

Production build:

```bash
npm run build
npm run preview
```

## GitHub Pages (one-time setup)

1. Repository **Settings → Pages**
2. **Build and deployment**: Source = **GitHub Actions**
3. Merge to `main` / `master`: the **Documentation** workflow builds and deploys to `https://AAitorG.github.io/PhenoMe/`

If the site 404s, confirm **Actions** permissions allow **Read and write** for workflows and that the `github-pages` environment exists (created on first deploy).

## Content layout

```text
docs/
├── assets/                  # Canonical static files (Astro publicDir: logos, figures, tab icon)
├── src/
│   ├── assets/              # Full mirror of docs/assets/ from sync-assets (gitignored); not the source of truth
│   ├── content/docs/        # Markdown content
│   │   ├── index.mdx        # Home page (splash)
│   │   ├── concepts/        # Conceptual explainers (embeddings, distances, properties)
│   │   ├── guides/          # How-to guides
│   │   ├── advanced/        # Reference (API + HDF5 database protocol)
│   │   │   └── api/         # Auto-generated API docs
│   │   └── *.md / *.mdx     # Other pages (FAQ, glossary, workflows, etc.)
│   └── styles/              # Custom CSS
├── scripts/
│   ├── generate_api_docs.py  # API doc generator
│   └── fix_markdown_links.py # Link normalizer
├── astro.config.mjs         # Astro configuration
└── package.json             # npm scripts and dependencies
```

| Path | Role |
|------|------|
| `src/content/docs/` | Markdown pages (guides, reference, home) |
| `src/content/docs/advanced/api/` | Generated by `scripts/generate_api_docs.py` on each `npm run build` |
| `scripts/fix_markdown_links.py` | Normalizes Markdown links (slugified root-relative links, asset paths) and runs a build-time link/anchor validator |
| `assets/` | Canonical static assets (`logo.png`, `logo_horizontal.png`, `logo_minimal.png`, `pipeline_overview.png`, etc.); served at site root via `publicDir` |
| `src/assets/**` | Full copy of `assets/` from `sync-assets` for Starlight logo, MDX-relative imports, etc. (gitignored) |
| `astro.config.mjs` | Starlight theme, sidebar, `site` + `base` (set to `/PhenoMe/` for GitHub Pages), `publicDir: "./assets"` |

## npm scripts cheat sheet

All commands below are run from the `docs/` directory.

| Script | What it runs | When to use |
|--------|--------------|-------------|
| `npm run sync-assets` | Rebuilds `src/assets/` as a full copy of `assets/` | Manual refresh; also the first step of `dev` / `build` |
| `npm run fix-links` | `python3 scripts/fix_markdown_links.py` over `src/content/docs/` | Rarely; included in `dev` / `build` |
| `npm run dev` | `sync-assets` → `generate_api_docs.py` → `fix-links` → `astro dev` | Daily authoring loop |
| `npm run build` | Same prep as `dev`, then `astro build` → `dist/` | Full production build (CI runs this) |
| `npm run preview` | `astro preview` on the `dist/` output | Verify the exact production bundle |

## Editing

- **Narrative docs**: edit Markdown files under `src/content/docs/`. Changes appear in the dev server automatically.
- **API Reference**: improve **docstrings** in `phenome/`. Rebuild regenerates `advanced/api/`. Changes appear on the next `npm run dev` or `npm run build`.
  - **Optional**: Control section grouping with metadata in docstrings:
    ```python
    def my_function():
        """
        @section Advanced Analysis
        @order 10

        Function description here...
        """
    ```
- **Site Configuration**: Edit `astro.config.mjs` (title, logo, GitHub Pages base path, sidebar). Restart the dev server for changes to take effect.
