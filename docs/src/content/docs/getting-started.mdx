This page walks you from an empty environment to a first PCA plot of your
own images.

## 1. Requirements

- **Python** 3.12 or newer.
- **Hardware**: any CPU works; an NVIDIA GPU is strongly recommended for
  speed. See [Best practices - performance](/PhenoMe/guides/best-practices/performance/)
  for sizing.
- **OS**: Linux, macOS, Windows. `pykeops` is omitted gracefully on Windows.

## 2. Installation

Conda is the most reliable way to install PyTorch plus the computer-vision
stack. Pip works too with the provided lockfiles.

<Tabs>
  <TabItem label="Conda (recommended)" icon="seti:julia">
    <Steps>
    1. **Clone the repository**

       ```bash
       git clone https://github.com/AAitorG/PhenoMe.git
       cd PhenoMe
       ```

    2. **Install dependencies** for your hardware

       <Tabs>
         <TabItem label="GPU (CUDA)">
           ```bash
           conda env create -f envs/environment-gpu.yml
           conda activate phenome-gpu
           ```
         </TabItem>
         <TabItem label="CPU">
           ```bash
           conda env create -f envs/environment-cpu.yml
           conda activate phenome-cpu
           ```
         </TabItem>
       </Tabs>

    3. **Verify the install**

       ```python
       import torch
       from phenome import PhenoMe
       print(f"PhenoMe {PhenoMe.__version__} is ready!")
       print("GPU:", torch.cuda.is_available(),
             f"({torch.cuda.get_device_name(0)})" if torch.cuda.is_available() else "(CPU-only mode)")
       ```
    </Steps>
  </TabItem>

  <TabItem label="Pip (editable)" icon="seti:python">

<Aside type="tip" title="Device selection">
Always pass `device` explicitly so CPU/GPU behavior is obvious in the
code, especially for scripts shared with collaborators.

```python
import torch
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```

Pass the same `device` into `load_dinov2_model(...)` and `PhenoMe(...)`.
</Aside>

<details>
<summary>Install troubleshooting (click to expand)</summary>

| Symptom | Suggestion |
|---------|------------|
| `torch` not found or wrong CUDA | Reinstall torch from PyTorch instructions; match driver and wheel. |
| `opencv` / `h5py` build errors | Use conda-forge or the full conda env file. |
| `pykeops` fails (common on Windows) | Omit from optional deps; fallback backends are slower but work. |
| Import works but GPU not used | `import torch; print(torch.cuda.is_available())`; ensure `device` is passed into `PhenoMe(...)`. |

More in the [FAQ - installation](/PhenoMe/faq/#installation-and-setup).

</details>

## 3. Your first analysis

The snippet below runs the full pipeline on a folder of images. You can run
this in a **Python script** or a **Jupyter Notebook** cell.

:::tip[Ready-to-run version]
If you prefer a guided walkthrough with interactive widgets, start with
[Notebook 01 — Interactive quickstart](https://github.com/AAitorG/PhenoMe/blob/main/Notebooks/tutorials/01_interactive_quickstart.ipynb).
:::

<Steps>
1. **Setup & initialization**

   Load a vision model (DINOv2 by default) and create the pipeline.

   ```python
   import torch
   from phenome import PhenoMe, load_dinov2_model

   device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
   wrapper = load_dinov2_model(model_name="dinov2_vitb14_reg", device=device)
   pheno = PhenoMe(device=device, seed=42)
   ```

2. **Find and inspect images**

   A flat folder is fine. For grouped experiments (conditions, drugs,
   time points) add metadata via [path templates or CSV](/PhenoMe/guides/experiment-details/).

   ```python
   pheno.find_files("path/to/your/images")
   inspect_df = pheno.inspect_data()
   ```

3. **Extract visual fingerprints and properties**

   ```python
   pheno.process_images(wrapper)
   pheno.compute_properties(property_preset="basic")
   ```

   <Aside type="tip">
   Use `property_preset="intensity"` if you do not have masks. See the
   [Property reference](/PhenoMe/guides/property-reference/) for details.
   </Aside>

4. **Visualize**

   ```python
   pheno.plot_pca(color_by="condition")
   ```

   Replace `condition` with any metadata column present on your
   `file_df`. Use `pheno.get_available_metadata_keys()` to list them.
</Steps>
