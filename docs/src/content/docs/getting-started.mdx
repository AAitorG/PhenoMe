## 1. Requirements

- **Python**: 3.12 or newer.
- **Hardware**: An NVIDIA GPU is strongly recommended for faster processing, but it will also work on your CPU.

---

## 2. Installation

We highly recommend using a **Conda environment** to easily manage dependencies like `torch` and computer vision libraries. Alternatively, you can use Pip.

<Tabs>
  <TabItem label="Conda (Recommended)" icon="seti:julia">
    <Steps>
    1. **Clone the repository**
        ```bash
        git clone https://github.com/AAitorG/PhenoMe.git
        cd PhenoMe
        ```

    2. **Install dependencies**

        Choose the stack that matches your hardware:
        <Tabs>
          <TabItem label="GPU (CUDA)">
            ```bash
            conda env create -f envs/environment-gpu.yml
            conda activate phenome-gpu
            ```
          </TabItem>
          <TabItem label="CPU">
            ```bash
            conda env create -f envs/environment-cpu.yml
            conda activate phenome-cpu
            ```
          </TabItem>
        </Tabs>
    </Steps>
  </TabItem>

  <TabItem label="Pip (Editable)" icon="seti:python">
    <Steps>
    1. **Clone the repository**
        ```bash
        git clone https://github.com/AAitorG/PhenoMe.git
        cd PhenoMe
        ```

    2. **Select the stack you need**
        <Tabs>
          <TabItem label="GPU (CUDA)">

          </TabItem>
          <TabItem label="CPU">

        </Tabs>

  </TabItem>
</Tabs>

### Verify Installation

```python
from phenome import PhenoMe
print(f"PhenoMe ({PhenoMe.__version__}) is ready!")
```

:::note[Device Selection: GPU vs CPU]
When coding, you should explicitly set the device.
```python
import torch
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
```
Pass `device=device` to both `load_dinov2_model(...)` and `PhenoMe(...)` initialized instances.
:::

#### Installation troubleshooting

| Symptom | Suggestion |
|---------|------------|
| `torch` not found / wrong CUDA | Reinstall torch from PyTorch instructions; match driver and wheel. |
| `opencv` / `h5py` build errors | Use conda-forge for those libs or a full conda env file. |
| `pykeops` fails (common on Windows) | Omit from optional deps; pipeline uses slower fallbacks. |
| Import works but GPU not used | `import torch; print(torch.cuda.is_available())`; ensure to pass `device` into PhenoMe. |

## 3. Quick start: your first analysis

<Steps>
1. **Setup & Initialization**

    Load a vision model (DINOv2 by default) and initialize the framework.
    ```python
    import torch
    from phenome import PhenoMe, load_dinov2_model

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    wrapper = load_dinov2_model(model_name="dinov2_vitb14_reg", device=device)
    pheno = PhenoMe(device=device, seed=42)
    ```

2. **Find and inspect images**

    You can start with a **single folder** of images. For grouped experiments (conditions, drugs, time points), add metadata via path templates or CSV.
    ```python
    pheno.find_files("path/to/your/images")
    inspect_df = pheno.inspect_data()
    ```

3. **Extract visual fingerprints**

    ```python
    pheno.process_images(wrapper)
    pheno.compute_properties(property_preset="basic")
    ```
    :::tip
    Use `property_preset="intensity"` if you do not have masks. See the [Property reference](../guides/property-reference.md) for more details.
    :::

4. **Visualize results**

    ```python
    pheno.plot_pca(color_by="condition")
    ```
    *(Replace `condition` with a metadata column present on your `file_df`)*
</Steps>
