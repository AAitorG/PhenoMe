## What is PhenoMe?

**PhenoMe** is a reproducible phenotyping pipeline built around three ideas:

- **Embeddings as the common representation.** Any vision model that exposes
  features (DINOv2 by default) can be plugged in; all downstream analyses
  work on the resulting vectors.
- **Metadata as the experimental context.** File paths, CSVs, or custom
  callables tell the pipeline about conditions, doses, time points, plates,
  and wells.
- **Classical properties to keep results interpretable.** Shape, intensity,
  texture, and quality metrics are computed alongside the embeddings and
  can be correlated back into them.

## How it fits together

![Pipeline Overview](../../assets/pipeline_overview.png)

PhenoMe follows a modular 4-step workflow:

1.  **Discover** (Input Images) — `find_files` identifies your raw microscopy images and masks.
2.  **Embeddings** (A) — `process_images` handles preprocessing and batched inference through a vision model to extract **visual fingerprints** (embeddings).
3.  **Properties** (B) — `compute_properties` extracts explainable **classical features** (intensity, shape, texture) in parallel.
4.  **Analyze** (C) — The engine merges both branches for distance quantification, dimensionality reduction (PCA/UMAP), interactive plotting, and reporting.

The same four steps underpin every workflow. Everything else - interactive exploration, extension hooks - plugs into that backbone.
