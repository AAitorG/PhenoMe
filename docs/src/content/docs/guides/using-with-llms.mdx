This page is for scientists using PhenoMe. Most are not programmers, so a script should stay easy to read and follow. The workflow is in [Getting started](/PhenoMe/getting-started/) and [Common workflows](/PhenoMe/workflows/). People who change PhenoMe itself follow the repository `AGENTS.md`.

A developer assistant builds that scientist's analysis tool with `from phenome import PhenoMe, load_dinov2_model`. An analysis assistant runs a dataset: a handoff ends with `save_results` and the plots, and a summary reads the returned tables, `return_fig=True`, `get_run_settings()`, and `print_processing_pipeline()`.

Generated from the same docs build:

- [llms-small.txt](https://AAitorG.github.io/PhenoMe/llms-small.txt) — getting started, workflows, folder patterns, FAQ, this page, and MCP
- [llms-full.txt](https://AAitorG.github.io/PhenoMe/llms-full.txt) — the whole site, including the API reference
- [phenome-api.json](https://AAitorG.github.io/PhenoMe/phenome-api.json) — public methods and signatures

Look up a name in `phenome-api.json` or the [function location guide](/PhenoMe/function-location-guide/). Do not invent a method, preset, metadata key, or parameter.

## Constraints

- Import `from phenome import PhenoMe, load_dinov2_model`. Pass `device` into both. Omit `seed` unless a reproducible run was requested.
- Order: `find_files` → `process_images` → optional `compute_properties` → analysis or plots. `plot_pca`, `plot_tsne`, and `plot_umap` compute the projection themselves.
- Do not change logging, plot format, or report sections unless asked. `save_results` writes HDF5 only. Export settings with `export_experiment_config`, and add a Methods section with `include_run_settings=True`, only when asked.
- For a handoff, call `save_results`. Add `export_experiment_config`, `export_methods_markdown`, or `generate_report(..., include_run_settings=True)` only for the files the user should receive.
- For a summary, keep tables and `return_fig=True` figures in variables and read `get_run_settings()` or `print_processing_pipeline()`.
- Call `get_available_metadata_keys()` before `color_by`, filters, or `batch_metadata_key`.
- Folder patterns use `(name)` groups, as in [Using folder names](/PhenoMe/guides/experiment-details/path-templates/). Brace placeholders do not match.
- Preset names are `none`, `intensity`, `shape`, `basic`, `standard`, and `complete`. `intensity` does not need masks. See [Presets](/PhenoMe/guides/select-properties/presets/).
- Notebooks are dataset examples, not a second API.

For Cursor or Claude Desktop, see [MCP for PhenoMe](/PhenoMe/guides/mcp/).
