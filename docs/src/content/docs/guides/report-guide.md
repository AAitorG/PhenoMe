The HTML report is a self-contained file you can open in any browser and
share with collaborators. No Python or Jupyter required. It includes
interactive plots, distance analysis, clustering, correlations, and
image galleries.

Each section below lists the **parameter of [`generate_report`](/PhenoMe/advanced/api/report/)**
that controls it - useful when trimming a long report for a particular
audience.

## 1. Overview / data summary

**What it shows:** Basic counts and metadata distributions (for example
number of images per condition).

**How to use it:** Verify data loaded correctly. Check that conditions,
replicates, or other metadata are balanced if expected.

**Always included.** Adjust with `reference_filters=` to highlight the
control group.

## 2. Interactive plots (PCA, t-SNE, UMAP)

**What it shows:** 2D or 3D scatter plots of embeddings (or properties),
with each point representing one image. Points can be coloured by
metadata (for example condition) or property values.

**How to use it:**

- **Hover** over points to see image thumbnails, metadata, and property
  values.
- **Zoom and pan** to inspect clusters.
- **Identify structure**: are conditions separated? Any obvious clusters
  or outliers?
- **Compare methods**: PCA shows global structure; t-SNE and UMAP often
  reveal finer local groupings.

**Controlled by:** `include_dimensionality_reduction`,
`include_embedding_plot`, `color_by`.

## 3. Distance analysis

**What it shows:** How far each image or group is from a reference group
(for example controls). Typically displayed as box plots or KDE curves
per condition.

**How to read it:**

- **Higher distance** = more phenotypically different from the reference.
- **Wide distribution** = high heterogeneity within a condition.
- **Shifted distributions** = treated conditions differ from control;
  magnitude indicates effect size.

**How to act:** Conditions with a large median distance or wide spread
may warrant closer inspection; hover in the embedding plot to see
representative images.

**Controlled by:** `reference_filters`, `distance_source`,
`include_distance_analysis`.

## 4. Outliers

**What it shows:** Images flagged as statistical outliers (e.g. Z-score
> threshold) relative to their group or the full dataset.

**How to use it:** Outliers can be technical (imaging artefact,
segmentation error) or biological (rare phenotype). Inspect flagged
images to decide whether to exclude or investigate.

**Controlled by:** `include_outliers`, `outlier_threshold`.

## 5. Correlations

**What it shows:** Which classical properties (area, eccentricity,
intensity, ...) correlate most strongly with the embedding space axes
(PC1, PC2, ...).

**How to read it:**

- High `|r|` means the property drives separation along that axis.
- Example: "PC1 ↔ eccentricity (r = 0.88)" - the main mode of
  variation is cell elongation.

**How to act:** Use these as biological hypotheses. See
[Interpretability](/PhenoMe/guides/interpretability/) for multivariate extensions.

**Controlled by:** `include_correlations`, `top_k_features`.

## 6. Clustering

**What it shows:** GMM (or other) cluster assignments and prototype
images (representative cells per cluster).

**How to use it:**

- **Prototypes** show typical phenotypes per cluster.
- **Cluster labels** relate structure in the plot to discrete groups.
- **Composition** - does one drug enrich a specific cluster across
  conditions?

**Controlled by:** `include_clustering`, `n_clusters`.

## 7. Property statistics

**What it shows:** Aggregated statistics (mean, std, ...) of classical
properties per group.

**How to use it:** Compare morphometrics across conditions to quantify
differences suggested by the embedding plots.

**Controlled by:** `include_property_statistics`.

## 8. Image gallery

**What it shows:** Thumbnail samples of images, often grouped by
condition or cluster.

**How to use it:** Quick visual check of data quality and phenotypic
diversity; useful when sharing with collaborators who want to *see* the
data.

**Controlled by:** `include_image_gallery`.

## Generating the report

```python
pheno.generate_report(
    output_path="report.html",
    reference_filters={"condition": "Control"},
    include_clustering=True,
    include_correlations=True,
    include_image_gallery=True,
    top_k_features=10,
    n_clusters=5,
)
```

See the [Report API](/PhenoMe/advanced/api/report/) for every parameter.
