title: "How to Read Your Report"
---

A guide to understanding and using the standalone HTML report generated by PhenoMe.

---

## Overview

The HTML report is a self-contained file you can open in any browser and share with collaborators. No Python or Jupyter required. It includes interactive plots, distance analysis, clustering, correlations, and image galleries.

---

## Report Sections

### 1. Overview / Data Summary

**What it shows:** Basic counts and metadata distributions (e.g., number of images per condition).

**How to use it:** Verify your data loaded correctly. Check that conditions, replicates, or other metadata are balanced if expected.

---

### 2. Interactive Plots (PCA, t-SNE, UMAP)

**What it shows:** 2D or 3D scatter plots of your embeddings (or properties), with each point representing one image. Points can be colored by metadata (e.g., condition) or by property values.

**How to use it:**
- **Hover** over points to see image thumbnails, metadata, and property values.
- **Zoom and pan** to inspect clusters.
- **Identify structure:** Are conditions separated? Are there obvious clusters or outliers?
- **Compare methods:** PCA shows global structure; t-SNE and UMAP often reveal finer local groupings.

---

### 3. Distance Analysis

**What it shows:** How far each image (or group) is from a reference group (e.g., controls). Typically displayed as distributions (e.g., box plots or KDE curves) per condition.

**How to read it:**
- **Higher distance** = more phenotypically different from the reference.
- **Wide distribution** = high heterogeneity within a condition.
- **Shifted distributions** = treated conditions differ from control; magnitude indicates effect size.

**How to act:** Conditions with large median distance or wide spread may warrant closer inspection. For example, hover in the embedding plot to see representative images.

---

### 4. Outliers

**What it shows:** Images flagged as statistical outliers (e.g., Z-score > threshold) relative to their group or the full dataset.

**How to use it:** Outliers can be technical (imaging artifact, segmentation error) or biological (rare phenotype). Inspect the flagged images to decide whether to exclude or investigate further.

---

### 5. Correlations

**What it shows:** Which classical properties (e.g., area, eccentricity, intensity) correlate most strongly with the embedding space (e.g., PC1, PC2).

**How to read it:**
- High |r| means that property drives the separation along that axis.
- Example: "PC1 ↔ eccentricity (r = 0.88)" suggests the main mode of variation is cell elongation.

**How to act:** Use these as biological hypotheses. See [Interpretability Guide](interpretability.md) for details.

---

### 6. Clustering

**What it shows:** GMM (or other) cluster assignments and prototype images (representative cells for each cluster).

**How to use it:**
- **Prototypes** show typical phenotypes per cluster.
- **Cluster labels** can be used to relate structure in the plot to discrete groups.
- Compare cluster composition across conditions (e.g., does one drug enrich a specific cluster?).

---

### 7. Property Statistics

**What it shows:** Aggregated statistics (mean, std, etc.) of classical properties per group.

**How to use it:** Compare morphometrics across conditions (e.g., mean area, eccentricity, intensity) to quantify differences suggested by the embedding plots.

---

### 8. Image Gallery

**What it shows:** Thumbnail samples of images, often grouped by condition or cluster.

**How to use it:** Quick visual check of data quality and phenotypic diversity. Useful for sharing with collaborators who want to “see” the data.

---

## Generating the Report

```python
pheno.generate_report(
    output_path="report.html",
    reference_filters={'condition': 'Control'},
    include_clustering=True,
    include_correlations=True,
    include_image_gallery=True
)
```

See [Report Generation API](../reference/api/report.md) for all options (e.g., `top_k_features`, `n_clusters`, `outlier_threshold`).
