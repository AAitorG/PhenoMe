# Agent instructions for PhenoMe

This repository is the **PhenoMe** Python package (phenotyping with vision-model embeddings) plus an Astro Starlight docs site under `docs/`.

## Working in this repo

- Public API lives on `phenome.PhenoMe` and top-level re-exports in `phenome/__init__.py`. Prefer those over mixin internals.
- Narrative docs: `docs/src/content/docs/`. **Do not hand-edit** `docs/src/content/docs/advanced/api/` or `docs/src/content/docs/function-location-guide.md` — they are generated by `docs/scripts/generate_api_docs.py` from docstrings.
- Docstrings are NumPy-style. Keep interrogate coverage (`fail-under=95`).
- Quality: `ruff check phenome tests`, `ruff format phenome tests`, `mypy phenome`, `pytest` (see `pyproject.toml` and `CONTRIBUTING.md`).
- Do not change default logging, plot formats, report sections, or `save_results` outputs unless the user explicitly asked. LLM-oriented extras are opt-in (`export_experiment_config`, `include_run_settings=True`). Processing steps are logged at INFO; reprint with `print_processing_pipeline()` only if asked.

## Writing analysis scripts (not library code)

Follow [Using PhenoMe with LLMs](https://AAitorG.github.io/PhenoMe/guides/using-with-llms/):

1. `from phenome import PhenoMe, load_dinov2_model`
2. `find_files` → `process_images` → `compute_properties` → plots / analysis
3. Do not invent method names; use the [function location guide](https://AAitorG.github.io/PhenoMe/function-location-guide/)
4. Save settings only when requested: `export_experiment_config(...)`; Methods in the HTML report only with `include_run_settings=True`
5. Compact docs for chat tools: `https://AAitorG.github.io/PhenoMe/llms-small.txt`
